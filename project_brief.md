# Project Brief: JobPilot — My AI Job Switch Copilot

## Agent Name
jobpilot-agent

## Overview
An intelligent job switch copilot agent that helps candidates discover relevant software engineering roles, assess truthful fit against verified skills, tailor resumes without fabricating unverified claims, and manage application tracking with a Firestore persistence layer.

## Architecture
- **Framework**: ADK (Agent Development Kit) on Python
- **Model**: Gemini 3.8 Flash (`gemini-3.8-flash`)
- **Backend Database**: Google Cloud Firestore (`jobpilot_jobs`, `jobpilot_applications`)
- **Project ID**: `qwiklabs-gcp-04-5de1df139dd5`
